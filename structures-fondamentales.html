Logique et raisonnements

Une assertion (ou proposition) est un énoncé mathématique susceptible d'être vrai ou faux — et rien d'autre : « 2 + 2 = 4 » est une assertion, « Que Dieu nous protège ! » n'en est pas une.

Les connecteurs

Le « ou » mathématique est inclusif. L'implication est définie par P ⇒ Q ≡ Q ∨ ¬P : elle est donc vraie dès que P est fausse. Q ⇒ P est la réciproque de P ⇒ Q, et P ⇔ Q abrège (P ⇒ Q) ∧ (Q ⇒ P).

⇒ n'est pas « donc »

(1 = 2) ⇒ (6 > 7) est une assertion vraie. « 1 = 2 donc 6 > 7 » énonce deux faussetés et affirme une causalité. De même, « f est dérivable ⇒ f est continue » n'affirme ni l'une ni l'autre, alors que « f est dérivable donc f est continue » affirme les deux.

Conséquence pratique : dans une copie, on écrit donc, or, car, c'est-à-dire — pas les symboles logiques, et jamais les quantificateurs comme abréviations de français.

Les équivalences à connaître

¬(P ∧ Q) ⇔ (¬P) ∨ (¬Q) lois de De Morgan ¬(P ∨ Q) ⇔ (¬P) ∧ (¬Q) P ⇔ ¬(¬P) (P ⇒ Q) ⇔ (¬Q ⇒ ¬P) contraposition ((¬P) ⇒ (Q ∧ ¬Q)) ⇒ P raisonnement par l'absurde

Les quantificateurs

Une proposition peut dépendre d'une variable : P(x) est alors une fonction de E dans {Vrai, Faux}. On la quantifie :

∃x ∈ E, P(x) il existe x dans E tel que P(x) est vraie ∀x ∈ E, P(x) P(x) est vraie pour tout x de E ¬(∃x ∈ E, P(x)) ⇔ ∀x ∈ E, ¬P(x) ¬(∀x ∈ E, P(x)) ⇔ ∃x ∈ E, ¬P(x)

Deux pièges classiques : si E est vide, ∀x ∈ E, P(x) est toujours vraie ; et l'ordre des quantificateurs change tout — ∃x, ∀y, x + y ≥ 0 est fausse dans ℝ alors que ∀x, ∃y, x + y ≥ 0 est vraie annale.

(∀x, P(x) ∧ Q(x)) ⇔ (∀x, P(x)) ∧ (∀x, Q(x)) ∀ se distribue sur ∧ (∃x, P(x) ∨ Q(x)) ⇔ (∃x, P(x)) ∨ (∃x, Q(x)) ∃ se distribue sur ∨ (∃x, P(x) ∧ Q(x)) ⇒ (∃x, P(x)) ∧ (∃x, Q(x)) seulement une implication (∀x, P(x)) ∨ (∀x, Q(x)) ⇒ (∀x, P(x) ∨ Q(x)) seulement une implication

La récurrence

Pour prouver ∀n ≥ n₀, P(n), il suffit de prouver P(n₀) (initialisation) et ∀n ≥ n₀, P(n) ⇒ P(n+1) (hérédité). En récurrence forte, on peut supposer P vraie à tous les rangs de n₀ à n pour démontrer P(n+1).

Le principe repose sur une propriété de ℕ : toute partie non vide de ℕ admet un plus petit élément — on dit que ℕ est bien ordonné. Rien de tel dans ℝ : ]0,1[ est non vide et borné, sans plus petit ni plus grand élément.

Rédaction typeΣ n²

Considérons P(N) : Σn=0..N n² = N(N+1)(2N+1)/6.

Initialisation. P(0) est vraie : les deux membres valent 0.

Hérédité. Soit N ∈ ℕ, supposons P(N). Alors

Σn=0..N+1 n² = N(N+1)(2N+1)/6 + (N+1)² = (2N³ + 9N² + 13N + 6)/6

et par ailleurs (N+1)(N+2)(2N+3)/6 = (2N³ + 9N² + 13N + 6)/6. Les deux membres coïncident, donc P(N+1) est vraie.

Conclusion. P(N) est vraie pour tout N ∈ ℕ.

Ensembles

Les ensembles usuels

ℕ = {0, 1, 2, …} ℕ* = ℕ \ {0} ℕ_n = {0, 1, …, n} ℕ*_n = {1, …, n} (donc ℕ*₀ = ∅) ℤ = ℕ ∪ (−ℕ) ℚ = { p/q | p ∈ ℤ, q ∈ ℕ* } ℝ ℝ \ ℚ = les irrationnels ℂ = { x + iy | x, y ∈ ℝ } ℝ̄ = ℝ ∪ {−∞, +∞}

Attention aux objets un peu piégeux mais parfaitement corrects : {∅} ≠ ∅ (l'un a un élément, l'autre aucun), {∅, {∅}}, et {1, 2, 3} = {3, 1, 2} = {1, 3, 1, 2}, de cardinal 3.

Appartenance, inclusion, égalité

Appartenance x ∈ E
Relation entre un élément et un ensemble.
Inclusion A ⊂ B
Relation entre deux ensembles : ∀x ∈ A, x ∈ B. C'est une relation d'ordre (réflexive, transitive, antisymétrique) mais non totale : {0,1} et {1,2} ne sont pas comparables.
Égalité A = B
(A ⊂ B) et (B ⊂ A). C'est la formulation à utiliser en pratique pour prouver une égalité d'ensembles : on montre les deux inclusions.
∈ et ⊂ ne se remplacent pas

On a 1 ∈ [0,2] car 1 est un élément du segment, mais {1} ⊂ [0,2] car {1} est un ensemble. Une question de TD entière porte là-dessus.

Les opérations

A ∩ B = { x | x ∈ A et x ∈ B } ⋂ᵢ Aᵢ = { x | ∀i ∈ I, x ∈ Aᵢ } A ∪ B = { x | x ∈ A ou x ∈ B } ⋃ᵢ Aᵢ = { x | ∃i ∈ I, x ∈ Aᵢ } A \ B = { x ∈ A | x ∉ B } (B n'a pas à être inclus dans A) C_E(A) = E \ A = Aᶜ complémentaire de A dans E P(E) = { A | A ⊂ E } famille des parties de E A × B = { (a,b) | a ∈ A, b ∈ B } produit cartésien

Exemple : pour E = {1,2,3}, P(E) = {∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}} — huit parties, soit 2³.

Deux couples sont égaux quand leurs coordonnées le sont : (a,b) = (a′,b′) ⇔ (a = a′ et b = b′).

Les règles de calcul

A ∪ (B ∪ C) = (A ∪ B) ∪ C associativité A ∩ (B ∩ C) = (A ∩ B) ∩ C A ∪ B = B ∪ A, A ∩ B = B ∩ A commutativité A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) distributivité

La différence A \ B, elle, se comporte beaucoup moins bien : pas d'associativité, pas de commutativité. Les identités qui la concernent se démontrent toujours par double inclusion, élément par élément.

Méthode — prouver une égalité d'ensembles
  • Prendre x ∈ membre de gauche, traduire l'appartenance en assertion logique.
  • Manipuler l'assertion avec les règles logiques (De Morgan, distributivité).
  • Relire l'assertion obtenue comme une appartenance au membre de droite : cela donne ⊂.
  • Refaire dans l'autre sens — ou justifier que toutes les étapes étaient des équivalences.

Fonction et application

Une fonction f : E → F associe à tout x de E au plus un élément de F. L'ensemble des x qui ont une image est le domaine de définition Dom(f). Une application est une fonction telle que Dom(f) = E — tout élément de départ a une image.

Formellement, deux applications sont égales lorsqu'elles ont même ensemble de départ, même ensemble d'arrivée, et même valeur en chaque point : x ↦ √x de ℝ dans ℝ et de ℝ⁺ dans ℝ ne sont donc pas la même chose.

Injection, surjection, bijection

Tout se lit sur l'équation f(x) = y, d'inconnue x :

Composition

(g ∘ f)(x) = g(f(x)) h ∘ (g ∘ f) = (h ∘ g) ∘ f f et g injectives ⇒ g ∘ f injective f et g surjectives ⇒ g ∘ f surjective f et g bijectives ⇒ g ∘ f bijective, et (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹
Les deux réciproques partielles annale

Si g ∘ f est injective, alors f est injective. Si g ∘ f est surjective, alors g est surjective. Retenir le sens : l'information remonte vers la première appliquée pour l'injectivité, vers la dernière pour la surjectivité.

Et le critère pratique : si g ∘ f = Id_E et f ∘ g = Id_F, alors f est bijective, de réciproque g.

Méthode — montrer qu'une application est bijective
  • Voie 1. Injectivité : on part de f(x) = f(x′) et on aboutit à x = x′. Surjectivité : on se donne y et on exhibe un antécédent (le brouillon sert à résoudre f(x) = y, la copie ne montre que la vérification).
  • Voie 2. On devine la réciproque g et on vérifie g ∘ f = Id et f ∘ g = Id. Plus rapide quand on sait résoudre le système.
  • Cas fini. Si card E = card F et E fini, alors injective ⇔ surjective ⇔ bijective : une seule des deux suffit.
Exemple type annalef(x,y) = (x + 3y, x + y)

Injectivité. Si f(x,y) = f(x′,y′) alors x + 3y = x′ + 3y′ et x + y = x′ + y′. En soustrayant, 2y = 2y′ donc y = y′, puis x = x′.

Surjectivité. Soit (a,b) ∈ ℝ². Le système x + 3y = a, x + y = b donne y = (a − b)/2 et x = (3b − a)/2. On vérifie que f((3b−a)/2, (a−b)/2) = (a,b).

Réciproque. f⁻¹(a,b) = ((3b − a)/2, (a − b)/2).

Cardinaux et dénombrement

Équipotence
E et F sont équipotents (E ∼ F) s'il existe une bijection de E sur F. C'est une relation d'équivalence entre ensembles.
Ensemble fini, cardinal
E est fini s'il est vide ou équipotent à {1, …, n} ; cet entier n, unique, est le cardinal card E. Sinon E est infini.
Dénombrable
Fini, ou équipotent à ℕ. Tout sous-ensemble de ℕ est dénombrable ; ℤ, ℕ² et ℚ le sont aussi.

Ce que le cardinal impose

E fini, f : E → F f injective ⇒ card E ≤ card F f surjective ⇒ card E ≥ card F si card E = card F : bijective ⇔ injective ⇔ surjective E ⊊ F ⇒ card E < card F (E fini)

Cantor

Théorème (Cantor). Pour tout ensemble E, il n'existe pas de surjection E → P(E). La preuve tient en une ligne : si f en était une, on pose P = { x ∈ E | x ∉ f(x) }, et l'égalité P = f(a) donne l'absurdité a ∈ P ⇔ a ∉ P.

Corollaire. ℝ n'est pas dénombrable (argument de la diagonale). Donc card ℕ < card ℝ, et card E < card P(E) pour tout E : il n'existe pas de plus grand cardinal.

Nombres complexes

Définition et forme algébrique

ℂ est l'ensemble des couples (x,y) de réels munis de :

(x, y) + (x′, y′) = (x + x′, y + y′) (x, y) · (x′, y′) = (xx′ − yy′, xy′ + yx′)

En posant i = (0,1) et 1 = (1,0), on obtient i² = (−1,0) = −1 et l'écriture algébrique z = x + iy, avec x = Re(z) et y = Im(z). Muni de ces deux lois, ℂ est un corps.

Propriétés du module : |z̄| = |z| ; |z| = 0 ⇔ z = 0 ; |zz′| = |z||z′| ; |z/z′| = |z|/|z′| ; |zⁿ| = |z|ⁿ ; |Re z| ≤ |z| et |Im z| ≤ |z| ; et l'inégalité triangulaire ||z| − |z′|| ≤ |z − z′| ≤ |z| + |z′|.

Géométriquement, |z| est la distance de l'origine au point d'affixe z.

Équations polynomiales

Théorème de d'Alembert-Gauss. Tout polynôme non constant à coefficients complexes admet au moins une racine dans ℂ. Corollaire : un polynôme de degré n a exactement n racines dans ℂ, comptées avec leurs multiplicités.

Galois a montré qu'à partir du degré 5, il n'existe en général pas de formule exprimant les racines par radicaux : l'existence n'est pas la calculabilité.

Le second degré dans ℂ

Pour az² + bz + c = 0 avec a ≠ 0, on pose Δ = b² − 4ac, qui est maintenant un complexe quelconque. La racine carrée usuelle n'existant que sur ℝ⁺, on cherche δ tel que δ² = Δ : si Δ = r e^{iθ}, alors δ = √r · e^{iθ/2} convient.

Structures algébriques

Lois de composition interne

Une opération sur E est une application E × E → F ; quand F = E on parle de loi de composition interne. Elle peut être :

commutative ∀x, y, x ⋆ y = y ⋆ x associative ∀x, y, z, x ⋆ (y ⋆ z) = (x ⋆ y) ⋆ z distributive x ⋆ (y △ z) = (x ⋆ y) △ (x ⋆ z) (par rapport à une autre loi △) élément neutre e tel que ∀x, e ⋆ x = x ⋆ e = x symétrique de x y tel que x ⋆ y = y ⋆ x = e A ⊂ E stable ∀x, y ∈ A, x ⋆ y ∈ A

Deux résultats d'unicité qui servent tout le temps : une loi admet au plus un élément neutre ; si elle est de plus associative, chaque élément admet au plus un symétrique, noté x⁻¹ (ou −x en notation additive). On a alors (x⁻¹)⁻¹ = x.

Groupes

Groupe
Un couple (G, ⋆) où ⋆ est une loi interne associative, admettant un élément neutre, et où tout élément a un symétrique. Il est commutatif (ou abélien) si ⋆ l'est.
Sous-groupe
Une partie A de G stable par ⋆, contenant le neutre et le symétrique de chacun de ses éléments. C'est alors un groupe pour la loi induite — c'est le critère à appliquer en exercice, plutôt que de revérifier les axiomes.
Ordre d'un élément
Le plus petit entier p ≥ 1 tel que xᵖ = e s'il existe (0 sinon). L'ensemble des n vérifiant xⁿ = e est alors exactement pℤ.

Dans un groupe, on peut simplifier : a⋆x = a⋆y ⇒ x = y. Et attention à l'ordre dans l'inverse d'un produit : (xy)⁻¹ = y⁻¹x⁻¹.

Théorème de Lagrange. Si G est un groupe fini et H un sous-groupe, alors card H divise card G.

Anneaux et corps

Un anneau (A, +, ·) : (A,+) est un groupe commutatif, la multiplication est associative, distributive sur +, et admet un neutre 1_A. On note Inv(A) l'ensemble des inversibles ; c'est un groupe.

C'est un corps lorsque A \ {0} = Inv A : tout élément non nul est inversible.

(ℤ, +, ·) anneau commutatif, pas un corps : Inv ℤ = {−1, 1} (ℚ, +, ·), (ℝ, +, ·), (ℂ, +, ·) corps commutatifs Mₙ(ℝ) anneau non commutatif dès n ≥ 2 ℤ/pℤ corps si et seulement si p est premier

Morphismes

φ : (G,⋆) → (G′,·) est un morphisme de groupes si ∀x,y, φ(x ⋆ y) = φ(x) · φ(y). Son noyau est ker φ = φ⁻¹({e′}). Un morphisme bijectif est un isomorphisme.

Alors φ(e) = e′, φ(g⁻¹) = φ(g)⁻¹, Im φ est un sous-groupe de G′ et ker φ un sous-groupe de G. Exemples : t ↦ eᵗ de (ℝ,+) sur (ℝ⁺*,·) ; t ↦ e^{it} de (ℝ,+) dans (ℂ*,·), d'image le cercle unité ; n ↦ gⁿ de (ℤ,+) dans G, de noyau pℤ où p est l'ordre de g.

Divisibilité dans ℤ

a | b ⇔ ∃c, ac = b a divise b Div(a₁,…,aₙ) = diviseurs communs Mult(a₁,…,aₙ) = multiples communs PGCD(a, b) = a ∧ b PPCM(a, b) = a ∨ b a et b premiers entre eux ⇔ a ∧ b = 1 ab = (a ∧ b)(a ∨ b)

Division euclidienne. Pour a ∈ ℤ et b ∈ ℕ*, il existe un unique couple (q, r) avec a = bq + r et 0 ≤ r < b. Le quotient est ⌊a/b⌋, et b | a ⇔ r = 0. Attention aux négatifs : la division de −17 par 5 donne (−4, 3), pas (−3, −2).

Identité de Bezout. ∃u, v ∈ ℤ, ua + vb = a ∧ b. En particulier a ∧ b = 1 ⇔ ∃u,v, ua + vb = 1 (théorème de Bezout). Les coefficients u, v ne sont pas uniques : on les obtient en remontant l'algorithme d'Euclide.

Lemme de Gauss. Si a est premier avec chaque bᵢ, il est premier avec leur produit.

Factorialité. Tout rationnel a > 0 s'écrit de manière unique a = p₁^{α₁} ⋯ pₙ^{αₙ} avec les pᵢ premiers croissants et αᵢ ∈ ℤ* ; a est entier si et seulement si tous les αᵢ sont positifs. L'exposant αᵢ est la valuation val_{pᵢ}(a), et :

val_p(ab) = val_p(a) + val_p(b) val_p(a/b) = val_p(a) − val_p(b) val_p(a ∧ b) = min(val_p a, val_p b) val_p(a ∨ b) = max(val_p a, val_p b) a | b ⇔ ∀p premier, val_p(a) ≤ val_p(b) √a ∈ ℚ ⇔ ∀p, val_p(a) ∈ 2ℤ (d'où √2 ∉ ℚ)

Et l'ensemble P des nombres premiers est infini : tout facteur premier de p₁p₂⋯pₙ + 1 échappe à la liste des n premiers.

Théorème des restes chinois. Si a₁, …, a_N sont deux à deux premiers entre eux et a = a₁⋯a_N, alors n ↦ (n mod a₁, …, n mod a_N) est une bijection de {0, …, a−1} sur ℤ/a₁ℤ × … × ℤ/a_Nℤ (et même un isomorphisme d'anneaux). Permutations

Groupe symétrique
Perm E = les bijections de E dans E, muni de ∘. On note Sₙ = Perm(ℕ*ₙ), de cardinal n!.
Support et points fixes
Supp σ = { x | σ(x) ≠ x } et Fix σ = E \ Supp σ. Deux permutations à supports disjoints commutent.
Cycle
(a₀, a₁, …, a_{P−1}) envoie chaque aₖ sur le suivant et le dernier sur a₀. Sa longueur P est aussi son ordre et le cardinal de son support. L'écriture n'est pas unique : on peut partir de n'importe quel élément du cycle.
Transposition
Un cycle de longueur 2. Elle est sa propre réciproque. Un cycle de longueur P se décompose en P − 1 transpositions : (a₀,…,a_{P−1}) = (a₀,a₁) ∘ … ∘ (a_{P−2},a_{P−1}).

Théorème de décomposition. Toute permutation se décompose en un produit de cycles à supports deux à deux disjoints, unique à l'ordre près. Leurs supports sont les orbites non réduites à un point, où Orb_σ(x) = { x, σ(x), …, σ^{P−1}(x) }.

ordre(σ) = PPCM des longueurs des cycles de sa décomposition ε(σ) = (−1)ⁿ si σ est produit de n transpositions = (−1)^{p₁−1} ⋯ (−1)^{p_q−1} avec pᵢ les longueurs des cycles ε(σ ∘ τ) = ε(σ) ε(τ) ε(transposition) = −1 ε(Id) = 1

σ est dite paire si ε(σ) = 1 ; les permutations paires forment le groupe alterné, sous-groupe de Perm E. Un carré σ² est toujours pair.

Méthode — la question type sur une permutation annale
  • Décomposer : partir de 0, écrire 0 → σ(0) → σ²(0) … jusqu'au retour ; fermer le cycle, reprendre avec le plus petit élément non encore traité.
  • Transpositions : chaque cycle de longueur P en donne P − 1, en chaîne.
  • Ordre : PPCM des longueurs. Signature : (−1) puissance le nombre total de transpositions.
  • σ⁻¹ : on retourne chaque cycle.
  • σ^N : on réduit N modulo l'ordre, puis on calcule σ^r cycle par cycle.
  • Existe-t-il une permutation d'ordre k ? Décomposer k en facteurs, chercher des longueurs de cycles disjoints dont le PPCM vaut k, et vérifier qu'il y a assez d'éléments — c'est presque toujours là que se joue la réponse négative.

Méthode — la limite par la définition, quatre fois sur cinq

Modèle : montrer que uₙ = (4n²+1)/(2n²+2) converge vers 2.

Soit ε > 0. Prenons n₀ ∈ ℕ tel que n₀ ≥ √(3/ε), et soit n ≥ n₀. |uₙ − 2| = 3/(2n² + 2) ≤ 3/(2n₀² + 2) ≤ 3/(2·(3/ε) + 2) ≤ 3ε/6 < ε.

Trois réflexes : calculer |uₙ − ℓ| et le simplifier en une seule fraction ; majorer en remplaçant n par n₀ ; choisir n₀ en fonction de ε et l'écrire. C'est l'exhibition de n₀ qui est notée.

Résoudre x² + bx + c = 0 dans ℤ/nℤ avec n = pq

  1. Factoriser modulo n : trouver α, β avec (x+α)(x+β) ≡ x² + bx + c — vérifier que α + β ≡ b et αβ ≡ c [n].
  2. z̄ est solution ⇔ n | (z+α)(z+β). Comme n = pq, quatre cas : n | z+α ; n | z+β ; p | z+α et q | z+β ; q | z+α et p | z+β.
  3. Les deux premiers cas donnent directement z ≡ −α et z ≡ −β.
  4. Les deux cas croisés se ramènent à une équation de Bezout pu − qv = β − α : on en tire une solution particulière puis la famille complète.
  5. Ramener chaque famille dans {0, …, n−1}.

Résultats des deux annales : x² + 5x + 41 = 0 dans ℤ/77ℤ a pour solutions {4, 26, 46, 68} ; x² + 18x + 10 = 0 dans ℤ/35ℤ donne les classes z ≡ 25 et z ≡ 27, en plus de −3 et −15.

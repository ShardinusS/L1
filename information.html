01

Du sens à la donnée

Information
Connaissance qui fait du sens pour les personnes concernées et qui peut être représentée par des symboles.
Le rôle de l'ordinateur
La notion de sens n'est pas pertinente pour un ordinateur. Machine purement matérielle, il agit uniquement sur la représentation de l'information. Un traitement informatique consiste donc à transformer ces représentations.
Donnée
Pour simplifier l'expression « représentation d'information », on utilise le terme équivalent de donnée. Dans un ordinateur, une donnée est toujours une succession de caractères 0 et 1.
02

La représentation binaire

Information dans une machine : le principe adopté est celui du « tout ou rien » — électronique numérique ou digitale, par opposition à l'électronique analogique.

Symboles 1 ou 0 = 1 bit ✱ (Binary digiT).

Bit — binary digit, chiffre binaire
Unité minimale d'information : deux valeurs possibles, 0 ou 1. On parle alors de représentation binaire.
Octet
Regroupement de 8 bits — un mot de 8 bits, comme 10110011.

Complexité. Un bit seul a peu d'intérêt : il faut combiner une multitude de bits, regroupés en ensembles, pour représenter une information complexe.

2e méthode — divisions successives

Principe : on divise le nombre par la base d'arrivée B′ de manière successive jusqu'à obtenir un quotient nul. Les calculs sont effectués dans la base de départ B. Le résultat s'obtient en lisant les restes successifs de bas en haut (du dernier reste au premier).

Exemple 2 — décimal vers binaireX = (235)₁₀
235 / 2 = 117 reste 1 ← chiffre de poids faible 117 / 2 = 58 reste 1 ↑ 58 / 2 = 29 reste 0 │ 29 / 2 = 14 reste 1 │ lecture 14 / 2 = 7 reste 0 │ de bas 7 / 2 = 3 reste 1 │ en haut 3 / 2 = 1 reste 1 │ 1 / 2 = 0 reste 1 ← chiffre de poids fort Résultat : (235)₁₀ = (11101011)₂

3e méthode — soustractions successives

Par une table de puissances de 2 — cas particulier décimal → binaire.

  1. Précalculer une table des puissances de 2.
  2. Considérer le nombre X.
  3. Dans la table, rechercher la plus grande puissance de 2 (notée 2i) inférieure ou égale au nombre X.
  4. Placer un bit « 1 » à la position i (mémoriser i).
  5. Soustraire cette puissance 2i au nombre X : X ← X − 2i.
  6. Si le résultat de la soustraction est différent de 0, recommencer à partir de l'étape 3. Sinon, compléter les positions restantes non sélectionnées par des « 0 ».

05

Complément — les nombres fractionnaires

Principe de base : trouver la représentation de la partie fractionnaire d'un nombre (les chiffres après la virgule). Si le chiffre C est placé n emplacements après la virgule dans la base B, il est interprété par le calcul C × B−n.

Algorithme de conversion — multiplications successives

  1. Dans la base B, procéder par multiplications successives de la partie fractionnaire par la base d'arrivée B′.
  2. Lors de la i-ème multiplication, la partie entière du résultat obtenu donne le chiffre à l'indice i après la virgule.
  3. Si la partie fractionnaire restante est différente de 0, recommencer le processus avec celle-ci.
06

Les entiers non signés

Un bit isolé a peu d'intérêt : on regroupe un ensemble de bits, ce qui suppose de définir un format d'écriture — l'écriture binaire complétée à gauche par des 0.

Capacité de représentation

FormatIntervalleValeur max
Sur n bits[0 ; 2ⁿ − 1]2ⁿ − 1
Sur 1 octet (8 bits)[0 ; 255]255
Sur 4 octets (32 bits)[0 ; 2³² − 1]≈ 4·10⁹

Opérations arithmétiques

On utilise les algorithmes classiques pour effectuer les opérations arithmétiques de base. Attention au résultat : il peut être erroné en cas de dépassement de la capacité de représentation.

Cas correct — 147 + 74 sur un octet corrigé= 221
10010011 (147) + 01001010 ( 74) ────────── 11011101 → vérification en base 10 : 221 ✓
Cas de dépassement — 147 + 200 sur un octet= 91 ✗
10010011 (147) + 11001000 (200) ────────── 1 01011011 ← 9 bits : le bit de poids fort est perdu 01011011 → lu en base 10 : 91 au lieu de 347 Dépassement de capacité : 347 > 255, le résultat ne tient pas sur un octet.

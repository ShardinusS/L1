Le système d'exploitation

Le système d'exploitation sert à faire fonctionner notre PC : Windows, Linux, macOS, iOS, Android.

Objectif du cours : la ligne de commande, pour manipuler Linux.

bash
$ echo bonjour
bonjour        # echo répète ce que j'écris
02

L'arborescence de fichiers

Les fichiers sont rangés dans des répertoires, eux-mêmes rangés dans d'autres répertoires : c'est l'arborescence. Elle part d'un point unique, la racine.

/                     ← la racine
├── home
│   └── kenzo         ← répertoire courant « . »
│       ├── cours
│       └── notes.txt
├── etc
└── var
/La racine de l'arborescence.
.Le répertoire courant — « moi ».
..Le répertoire père. D'où cd .. pour remonter d'un cran.
03

Se repérer et se déplacer

pwdAffiche l'emplacement courant dans l'arborescence.
lsListe tous les fichiers du répertoire.
ls -lListe les fichiers avec plus d'informations : les lignes qui commencent par d sont des dossiers, celles qui commencent par - sont des fichiers.
ls -aAffiche aussi les fichiers cachés : tous les fichiers dont le nom commence par un . ne s'affichent pas par défaut.
cdChange de répertoire.
fileDétermine le type d'un fichier.
ls -l — lecture de la première colonne complément
$ pwd
/home/kenzo
$ ls -l
drwxr-xr-x  2 kenzo kenzo  4096  7 sept. 15:54 cours     # d → répertoire
-rw-r--r--  1 kenzo kenzo   128  7 sept. 15:56 notes.txt # - → fichier
04

Créer des fichiers et des répertoires

mkdirCrée un répertoire.
touchCrée un fichier (vide).
nanoÉdite un fichier dans un éditeur de texte.

Trois façons de créer un fichier : touch, une redirection, ou un éditeur de texte.

Les redirections

commande > fichier.txtÉcrit dans le fichier le texte affiché par la commande — le contenu précédent est écrasé. ✱
commande >> fichier.txtAjoute le texte affiché à la fin du fichier, sans rien effacer.
redirections
$ echo bonjour > notes.txt   # crée (ou écrase) notes.txt
$ echo au revoir >> notes.txt # ajoute une ligne à la fin
$ cat notes.txt
bonjour
au revoir
05

Lire le contenu d'un fichier

catVoir le contenu du fichier, d'un seul bloc.
lessAffiche le contenu d'un fichier page par page.
headAffiche juste le début d'un fichier.
tailAffiche la fin d'un fichier.
-n 3Avec head ou tail : les 3 premières ou 3 dernières lignes.
wcDonne le nombre de lignes, de mots et de caractères.
06

Copier, déplacer, supprimer

cp source destinationCopie un fichier.
mvRenomme ou déplace un fichier.
rmSupprime un fichier.
rmdirSupprime un répertoire sans fichiers à l'intérieur.
Pas de corbeille

rm supprime définitivement : rien n'est mis de côté, rien ne se récupère.

07

Obtenir de l'aide

man commandeAffiche le manuel de la commande. — je connais la commande, je cherche ses options.
aproposCherche la commande à utiliser pour faire quelque chose. — je connais le besoin, je cherche la commande.
08

Composer des commandes

cutSélectionner.
pasteAssembler.
sortTrier.
sort -rTrier dans le sens inverse.
sort -nTrier de manière numérique.
uniqSi quelque chose est présent en plusieurs exemplaires, n'en laisse qu'un seul.
|Le pipe (tube) : sert à combiner deux commandes, la sortie de la première devient l'entrée de la seconde.

Les options de sélection ✱

OptionCommandeRôle
:—Le séparateur utilisé dans le fichier (exemple : /etc/passwd).
-dcutDélimiteur : indique quel caractère sépare les colonnes — -d:
-fcutChamp : la colonne que je veux garder — -f1
-ccutCaractère : les caractères que je veux garder — -c1-5
-ksortChamp de tri : la colonne sur laquelle trier — -k2
cut | sort | uniq complément
$ cut -d: -f7 /etc/passwd | sort | uniq
/bin/bash
/bin/false
/usr/sbin/nologin
# cut : 7e champ, séparé par « : » → sort : trie → uniq : un seul exemplaire

uniq ne supprime que les doublons consécutifs : c'est pour cela qu'on trie avec sort juste avant.
